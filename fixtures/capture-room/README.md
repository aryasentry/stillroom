# Synthetic multi-view reconstruction fixture

CC0-1.0, generated by `scripts/generate_capture_fixture.mjs`. These are rendered photographs of an open-front synthetic room, with deliberately rich fixed surface detail to make a favourable reconstruction case. They are not images of a real place.

Give only the `images/` files to Stillroom. The reconstruction pipeline must estimate cameras from those images; `ground-truth.json` and the source geometry are verification material and must not be inputs. The original geometry is never a substitute for a reconstructed result.

Regenerate with `STILLROOM_BROWSER_CHANNEL=chrome node scripts/generate_capture_fixture.mjs`. Requires the existing frontend dependencies and installed Chrome. Rendering may vary slightly across browser/GPU versions.
